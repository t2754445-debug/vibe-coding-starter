Что установить

Инструкции для macOS, по шагам сверху вниз. Каждый шаг заканчивается проверкой — не переходи к следующему, пока текущий не дал ожидаемый результат. Переключатель в шапке меняет инструкции на Windows.

Инструкции для Windows 10/11, по шагам сверху вниз. Каждый шаг заканчивается проверкой — не переходи к следующему, пока текущий не дал ожидаемый результат. Переключатель в шапке меняет инструкции на macOS.

Всё живёт внутри VS Code. Редактор, терминал, Git, Docker и AI-агент — одно окно, переключаться между программами не придётся. Встроенный терминал открывается сочетанием Ctrl + ` (клавиша с буквой «ё»), и все команды с этой страницы вводятся именно туда.

Три главные вещи — VPN, VS Code и Docker. Остальное обвязка: ставится быстро и почти без вопросов.

01

Happ — VPN-клиент

обязательно доступ

Ставим первым: без него не пройдёт всё остальное. Сайты и API OpenAI и Anthropic из России не открываются, часть сервисов GitHub — тоже. Нужен VPN, который работает постоянно, а не «пять минут в день» — иначе AI-агент оборвётся посреди задачи.

Приложение бесплатное, платишь только за подписку на сервер. Ставь Happ и на компьютер, и на телефон — подписка одна, работает на обоих.

  1. Скачай Happ для macOS — файл Happ.macOS.universal.dmg, подходит и для Apple Silicon, и для Intel.
  2. Открой скачанный .dmg и перетащи Happ в папку Applications.
  3. Первый запуск — правой кнопкой по значку → «Открыть», затем ещё раз «Открыть» в предупреждении. Через двойной клик macOS не пустит незнакомое приложение.
  4. Разреши добавить конфигурацию VPN — система попросит пароль или Touch ID.
  5. Нажми «+» и вставь ссылку-подписку, которую я пришлю. Выбери сервер и включи тумблер.

На iPhone и iPad — то же приложение из App Store, подписка вставляется точно так же.

  1. Скачай Happ для Windows с сайта happ.info и запусти установщик.
  2. Разреши приложению добавить конфигурацию VPN.
  3. Нажми «+» и вставь ссылку-подписку, которую я пришлю. Выбери сервер и включи тумблер.

На iPhone и Android — то же приложение из App Store и Google Play, подписка одна на все устройства.

Ссылку-подписку пришлю отдельно. Бесплатные публичные VPN из рекламы не бери: они медленные и торгуют твоим трафиком. Запасной вариант, если Happ не подойдёт, — Outline.

Проверка: открой chatgpt.com и claude.ai — обе страницы должны загрузиться.

02

Терминал и Homebrew

обязательно фундамент

Homebrew — пакетный менеджер для macOS. Через него всё остальное ставится одной командой, без хождения по сайтам и перетаскивания иконок. На Mac это самый короткий путь.

  1. Нажми Cmd + пробел, набери «Терминал», Enter.
  2. Скопируй команду целиком, вставь в терминал, нажми Enter: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Введи пароль от Mac. Символы при вводе не отображаются — это нормально, просто печатай и жми Enter.
  4. Ещё раз Enter для подтверждения. Дальше 5–15 минут ожидания: подтянутся Xcode Command Line Tools, без них не работает Git.
  5. В конце Homebrew напечатает блок «Next steps» с двумя командами. Их обязательно нужно выполнить — иначе система не найдёт brew. Для Mac на Apple Silicon это: echo >> ~/.zprofile echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"
  6. Закрой терминал и открой заново.

Проверка: команда brew --version отвечает номером версии, а не command not found.

brew.sh

03

Visual Studio Code

обязательно рабочая среда

Главная программа. Здесь ты пишешь код, здесь же терминал, Git и AI-агент. Бесплатный, самый распространённый редактор — под него есть всё. Не путай с Visual Studio: это другая, тяжёлая среда для C#.

Через Homebrew — одна команда:

brew install --cask visual-studio-code

Или вручную: на сайте нажми «Mac Universal», распакуй архив и перетащи Visual Studio Code в папку Applications.

Дальше две настройки, обе нужны:

  1. Запусти VS Code, нажми Cmd + Shift + P, набери shell command и выбери «Install 'code' command in PATH». После этого любую папку можно открыть из терминала командой code .
  2. Открой встроенный терминал: Ctrl + `. Это твоё основное рабочее место — все команды дальше вводятся сюда.
  1. Скачай User Installer для Windows x64.
  2. При установке поставь галочки «Add to PATH» и «Открывать через контекстное меню».
  3. Запусти VS Code и открой встроенный терминал: Ctrl + `. Это твоё основное рабочее место.

Проверка: VS Code открыт, внизу видна панель терминала, команда code --version в нём отвечает номером версии.

code.visualstudio.com/download
04

Docker Desktop

обязательно окружения

Docker запускает базы данных, серверы и чужие проекты в изолированных контейнерах — не засоряя систему и не ломая то, что уже стоит. Дойдём до PostgreSQL, Redis или чужого репозитория — вместо часа установок будет одна команда. Ставим заранее: качается долго и должен работать в фоне.

Через Homebrew — он сам выберет сборку под твой процессор:

brew install --cask docker

Если ставишь вручную с сайта — для Mac на M1–M4 жми кнопку «Download for Mac – Apple Silicon». Intel-версия на них тоже пойдёт, но заметно медленнее.

  1. Запусти Docker Desktop из Launchpad.
  2. Разреши установку служебного компонента — попросит пароль от Mac.
  3. Прими условия и дождись, пока значок кита в верхней строке перестанет мигать.
  1. Скачай Docker Desktop for Windows и запусти установщик.
  2. Он предложит включить WSL 2 — соглашайся и перезагрузи компьютер.
  3. Запусти Docker Desktop и дождись статуса «Engine running» внизу окна.

Проверочная команда во встроенном терминале VS Code — скачает и запустит тестовый контейнер:

docker run hello-world

Проверка: в ответ приходит «Hello from Docker!». Если пишет «Cannot connect to the Docker daemon» — Docker Desktop просто не запущен.

docker.com — Docker Desktop

Git

обязательно история версий

Система контроля версий: сохраняет каждый шаг проекта и позволяет откатиться, если нейросеть что-то сломала. Без Git вайб-кодинг превращается в рулетку — это твоя кнопка «отменить» для всего проекта целиком.

В macOS есть старая встроенная версия, ставим свежую:

brew install git

Скачай установщик и прокликай его по умолчанию — ничего менять не нужно.

После установки один раз представься Git — подставь своё имя и почту:

git config --global user.name "Ivan Petrov" git config --global user.email "ivan@example.com"

Проверка: git --version отвечает номером версии.

git-scm.com/download/mac git-scm.com/download/win

Короткий путь для Mac. Когда Homebrew уже стоит, шаги 3–7 ставятся двумя строками:

brew install git node python brew install --cask visual-studio-code docker

Остаётся настроить Git, включить команду code в PATH и запустить Docker Desktop.

Проверка, что всё встало

Закрой все окна терминала, открой VS Code, открой встроенный терминал (Ctrl + `) и выполни команды подряд. Каждая должна вернуть номер версии, а не ошибку.

brew --version # Homebrew 4.x code --version # 1.10x.x docker --version # Docker version 27.x git --version # git version 2.4x node -v # v22.x.x npm -v # 10.x.x python3 --version # Python 3.12+

Если терминал отвечает command not found — программа встала, но оболочка её не видит. Самая частая причина на Mac: не выполнены команды eval "$(/opt/homebrew/bin/brew shellenv)" из шага 2. Выполни их и перезапусти терминал.

code --version # 1.10x.x docker --version # Docker version 27.x git --version # git version 2.4x node -v # v22.x.x npm -v # 10.x.x python --version # Python 3.12+

Если команда отвечает «не является внутренней или внешней командой» — программа встала, но не прописалась в PATH. Самая частая причина: забытая галочка у Python. Лечится переустановкой с правильной галочкой.

Чем будем работать

Все эти инструменты пишут код, но различаются не столько «умом» модели, сколько формой доступа: автодополнение в редакторе, агент в терминале или сырой API с оплатой по факту. Цены — ориентир, тарифы меняются, сверяйся на сайте.

Главная мысль: инструмент не заменяет понимание. Нейросеть уверенно напишет код, который не работает, и так же уверенно объяснит, почему он правильный. Твоя задача на первых месяцах — не научиться быстро генерировать, а научиться читать сгенерированное и замечать, где оно врёт.

Первый проект за 15 минут

Когда всё установлено — открой встроенный терминал VS Code и пройди эти шаги. Это полный рабочий цикл в миниатюре: папка, история версий, агент, результат, сохранение.

mkdir -p ~/Projects/hello-vibe # создать папку проекта cd ~/Projects/hello-vibe # перейти в неё code . # открыть её в VS Code git init # включить историю версий codex # запустить агента
mkdir C:\Projects\hello-vibe # создать папку проекта cd C:\Projects\hello-vibe # перейти в неё code . # открыть её в VS Code git init # включить историю версий codex # запустить агента

Дальше пишешь агенту задачу человеческим языком — например: «Сделай одностраничный сайт-визитку на HTML и CSS: имя, короткое описание, три ссылки. Тёмная тема, шрифт без засечек. Открой результат в браузере». Он создаст файлы сам.

Когда результат устраивает — фиксируешь его, чтобы было куда откатиться:

git add . git commit -m "Первая версия визитки"

Всё. С этого момента любой эксперимент безопасен: сломал — вернулся к последнему коммиту.

Пять ошибок, на которых спотыкаются все

  • Работать без коммитов Агент за один заход правит десяток файлов. Без Git ты не отличишь, что он улучшил, а что сломал, и не вернёшься назад. Коммить после каждого работающего шага.
  • Ставить задачу одним словом «Сделай сайт» даёт случайный результат. Опиши, что именно, для кого, на чём и как должно выглядеть. Чем точнее вход, тем меньше переделок.
  • Принимать код, не читая Не понял, что делает функция — попроси объяснить построчно. Непонятый код становится неисправимым багом ровно через неделю.
  • Класть ключи и пароли прямо в код API-ключи хранят в файле .env, а сам .env вносят в .gitignore. Иначе ключ уедет в публичный репозиторий и его найдут за часы.
  • Копить изменения огромными кусками Проси одну задачу за раз и сразу проверяй результат. Двадцать правок за один запрос почти гарантированно приедут с ошибкой, которую потом не локализовать.

Программы

1. Happ — VPN https://happ.info/ Прямая ссылка на Mac-версию: Happ.macOS.universal.dmg На странице выбери кнопку Windows.
1a. Happ для iPhone https://apps.apple.com/us/app/happ-proxy-utility/id6504287215 Та же подписка работает и на телефоне, и на компьютере. Ссылку-подписку пришлю отдельно.
1b. Outline — запасной VPN https://getoutline.org/get-started/ Ставить только если Happ не подойдёт.
2. Homebrew https://brew.sh Команда установки — на главной странице. Через него ставится всё остальное.
2. Windows Terminal https://apps.microsoft.com/detail/9n0dx20hk701
3. Visual Studio Code https://code.visualstudio.com/download Кнопка «Mac Universal». Или командой brew install --cask visual-studio-code Кнопка «User Installer x64».
4. Docker Desktop https://www.docker.com/products/docker-desktop/ Для M1–M4 — кнопка «Apple Silicon». Или командой brew install --cask docker Потребует включить WSL 2 и перезагрузиться.
5. Git https://git-scm.com/download/mac Проще командой: brew install git
5. Git https://git-scm.com/download/win
6. Node.js LTS https://nodejs.org/en/download Проще командой: brew install node
7. Python https://www.python.org/downloads/macos/ Проще командой: brew install python
7. Python https://www.python.org/downloads/windows/ Галочка «Add python.exe to PATH» в первом окне.
8. Почта Gmail https://accounts.google.com/signup Новый ящик, регистрировать с включённым VPN. На него завяжутся все подписки.
9. Аккаунт GitHub https://github.com/signup Регистрируй на тот же Gmail.
