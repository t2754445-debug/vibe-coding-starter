01

Happ — VPN

обязательно

Ставим первым: без него не пройдёт всё остальное. Сайты OpenAI и Anthropic из России не открываются, часть сервисов GitHub — тоже. Нужен VPN, который работает постоянно, а не «пять минут в день», иначе AI-агент оборвётся посреди задачи.

Скачать Happ для Mac Happ.macOS.universal.dmg Happ для iPhone и iPad App Store

Как установить

  1. Открой скачанный файл Happ.macOS.universal.dmg двойным щелчком.
  2. В открывшемся окне перетащи значок Happ в папку Applications.
  3. Открой Launchpad и найди Happ. Нажми на значок правой кнопкой → «Открыть», потом ещё раз «Открыть» в предупреждении. Обычный двойной щелчок macOS заблокирует — так система относится к незнакомым приложениям.
  4. Разреши добавить конфигурацию VPN — попросит пароль от Mac или Touch ID.
  5. Нажми «+» и вставь ссылку-подписку, которую я пришлю. Выбери сервер и включи тумблер.

То же приложение поставь на телефон — подписка одна, работает на всех устройствах сразу.

Скачать Happ для Windows happ.info

Как установить

  1. На сайте выбери кнопку Windows и скачай установщик.
  2. Запусти его и прокликай по умолчанию.
  3. Разреши приложению добавить конфигурацию VPN.
  4. Нажми «+» и вставь ссылку-подписку, которую я пришлю. Выбери сервер и включи тумблер.

Ссылку-подписку пришлю отдельно. Бесплатные публичные VPN из рекламы не бери: они медленные и торгуют твоим трафиком. Запасной вариант, если Happ не подойдёт, — Outline.

Проверка: открой chatgpt.com — страница должна загрузиться.

02

Visual Studio Code

обязательно

Главная программа, в которой будем работать. Здесь ты пишешь код, здесь же живут AI-агенты. Бесплатная. Не путай с Visual Studio — это другая, тяжёлая программа для C#.

Скачать VS Code code.visualstudio.com/download

Как установить

  1. На странице нажми большую кнопку «Mac Universal» — она подходит и для M1–M4, и для старых Intel.
  2. Скачается архив. Открой его двойным щелчком — появится приложение Visual Studio Code.
  3. Перетащи его в папку Applications, иначе при каждом обновлении будет ругаться.
  4. Запусти. Если macOS спросит «вы уверены» — нажми «Открыть».
  5. Слева в меню нажми на значок с квадратиками (Extensions), найди Russian Language Pack и установи, если хочешь русский интерфейс. Не обязательно.

Как установить

  1. На странице нажми кнопку Windows — скачается VSCodeUserSetup-x64.exe.
  2. Запусти установщик. На шаге «Выберите дополнительные задачи» поставь галочку «Add to PATH» — она нужна дальше.
  3. Дождись конца установки и запусти VS Code.
  4. Слева в меню нажми на значок с квадратиками (Extensions), найди Russian Language Pack и установи, если хочешь русский интерфейс. Не обязательно.
Короткий путь через терминал — не обязательно

Если уже стоит Homebrew, вся установка — одна строка:

brew install --cask visual-studio-code

Проверка: VS Code открывается и показывает стартовый экран.

03

Docker Desktop

обязательно

Docker запускает базы данных, серверы и чужие проекты в отдельных «коробках» — не засоряя систему и не ломая то, что уже стоит. Дойдём до баз данных — вместо часа установок будет одна команда. Ставим заранее: качается долго, файл тяжёлый.

Скачать Docker Desktop docker.com/products/docker-desktop

Как установить

  1. На сайте нажми «Download for Mac – Apple Silicon», если у тебя M1, M2, M3 или M4. Если Mac старый, на процессоре Intel — соседнюю кнопку «Intel Chip».

    Посмотреть, какой у тебя процессор: значок Apple в левом верхнем углу → «Об этом Mac».

  2. Открой скачанный Docker.dmg и перетащи Docker в папку Applications.
  3. Запусти Docker из Launchpad, прими условия.
  4. Он попросит пароль от Mac, чтобы доустановить служебную часть — введи.
  5. Дождись, пока значок кита в верхней строке перестанет мигать. Мигает — значит, ещё запускается.

Как установить

  1. Нажми «Download for Windows» и запусти установщик.
  2. Он предложит включить WSL 2 — соглашайся.
  3. Перезагрузи компьютер, когда попросит.
  4. Запусти Docker Desktop и дождись надписи «Engine running» внизу окна.
Короткий путь через терминал — не обязательно

Homebrew сам подберёт нужную сборку под процессор:

brew install --cask docker

Проверить, что всё работает:

docker run hello-world

Проверка: Docker Desktop запущен, кит не мигает, в окне видна вкладка «Containers».

04

Python

обязательно

Язык, на котором пишут автоматизацию, парсеры, обработку данных и всё, что связано с нейросетями. Ставим сам язык и расширение к нему в VS Code — дальше запускать программы можно будет одной кнопкой.

Скачать Python для Mac python.org/downloads/macos Скачать Python для Windows python.org/downloads/windows

Как установить

  1. На странице выбери последний стабильный выпуск 3.12 или новее и скачай файл с названием вида macOS 64-bit universal2 installer.
  2. Открой скачанный .pkg и прокликай установщик по умолчанию.
  3. В конце он откроет папку с файлами — можно просто закрыть её.
  4. Открой VS Code → Extensions (значок с квадратиками слева) → найди расширение Python от Microsoft → Install.

Как установить

  1. Скачай Windows installer (64-bit) последней версии 3.12 или новее.
  2. Запусти его и в первом же окне поставь галочку «Add python.exe to PATH». Это самая частая ошибка новичков — без галочки Python придётся переустанавливать.
  3. Нажми «Install Now» и дождись конца.
  4. Открой VS Code → Extensions (значок с квадратиками слева) → найди расширение Python от Microsoft → Install.
Короткий путь через терминал — не обязательно

Через Homebrew:

brew install python

На Mac команда называется python3, а не python — так и должно быть. Системный Python трогать нельзя.

Проверка: в VS Code создай файл test.py, напиши в нём print("привет") и нажми кнопку ▶ в правом верхнем углу. Внизу должно появиться слово «привет».

05

superwhisper — диктовка голосом

Диктовка голосом

рекомендую

Приложение, которое превращает речь в текст в любом окне: нажал горячую клавишу, надиктовал задачу агенту — получил готовый текст. Задачи для AI удобнее наговаривать, чем печатать: длинное описание голосом занимает секунд двадцать вместо трёх минут.

Работает локально на твоём Mac — запись никуда не отправляется. Есть бесплатный режим, платная версия точнее и быстрее.

Скачать superwhisper superwhisper.com

Как установить

  1. Скачай с сайта и перетащи в папку Applications.
  2. При первом запуске разреши доступ к микрофону и к универсальному доступу — без второго приложение не сможет вставлять текст в другие окна.
  3. Скачай модель, которую предложит мастер настройки. Для русского языка бери Large, если на Mac 16 ГБ памяти и больше; иначе Medium.
  4. Задай горячую клавишу — по умолчанию удерживание правой Cmd.
  5. Проверь: открой любое поле ввода, зажми клавишу, скажи фразу, отпусти — текст появится сам.

Альтернатива, если нужна не диктовка, а расшифровка готовых записей и видео, — MacWhisper.

Проверка: надиктованная фраза появляется текстом в открытом окне.

На Windows встроенная диктовка вызывается сочетанием Win + H — отдельно ничего ставить не нужно, но качество русского распознавания среднее.

Если нужна точная диктовка на уровне Whisper, ставь Wispr Flow — работает в любом окне, есть бесплатный тариф.

Скачать Wispr Flow wisprflow.ai

Проверка: надиктованная фраза появляется текстом в открытом окне.

Два аккаунта

Ставить ничего не надо — просто зарегистрироваться. Оба нужны до занятия: без них не получится ни оплатить подписку, ни сохранить проект.

Почта Gmail

Нужна обязательно: на mail.ru и Яндекс многие сервисы просто не регистрируют — OpenAI и Anthropic в том числе.

  • Заводи новый ящик, отдельно от личного — учебное и личное лучше не смешивать.
  • Регистрируйся с включённым VPN.
  • Запиши пароль и включи двухфакторную защиту: на этот ящик завяжутся все подписки.
Создать почту accounts.google.com/signup

Аккаунт GitHub

Бесплатное хранилище проектов в облаке: резервная копия, портфолио и вход в кучу сервисов одной кнопкой.

  • Регистрируй на тот же Gmail.
  • Придумай нормальное имя пользователя — оно будет видно в ссылках на твои проекты.
  • Подтверди почту и на этом остановись: настраивать ничего не надо.
Зарегистрироваться github.com/signup

Отметь, что уже сделал

Галочки сохраняются в браузере — можно закрыть страницу и вернуться позже. К занятию нужно, чтобы стояли все семь.

Готово: 0 из 7

Застрял — сразу пиши, не сиди. Установка ломается у всех, это часть процесса, а не признак того, что ты чего-то не понимаешь. Отдельно напиши, если что-то в этой памятке показалось непонятным: перепишу понятнее.

Удобнее всего прислать скриншот того, что видишь на экране, и написать, на каком шаге остановился: на Mac скриншот делается сочетанием Cmd + Shift + 4на Windows — клавишей Print Screen или сочетанием Win + Shift + S.

Терминал — это не страшно. Он встроен прямо в VS Code и открывается сочетанием Ctrl + ` (клавиша с буквой «ё»). Мы работаем в одном окне: слева файлы, посередине код, внизу терминал с агентом. Разберём на первом же занятии.

Чем будем работать

Все эти инструменты пишут код, но различаются не столько «умом» модели, сколько формой доступа: подсказка в редакторе, агент, который сам правит файлы, или ключ API с оплатой по факту. Цены — ориентир, тарифы меняются.

Если бюджет жмёт

$0–5 / мес

Бесплатный тариф Copilot в VS Code, а тяжёлое добиваем DeepSeek по API — пять долларов на счёте расходуются месяцами.

Главная мысль: инструмент не заменяет понимание. Нейросеть уверенно напишет код, который не работает, и так же уверенно объяснит, почему он правильный. Твоя задача на первых месяцах — не научиться быстро генерировать, а научиться читать сгенерированное и замечать, где оно врёт.

Пять ошибок, на которых спотыкаются все

  • Работать без сохранений Агент за один заход правит десяток файлов. Без Git ты не отличишь, что он улучшил, а что сломал, и не вернёшься назад. Сохраняй версию после каждого работающего шага.
  • Ставить задачу одним словом «Сделай сайт» даёт случайный результат. Опиши, что именно, для кого, на чём и как должно выглядеть. Чем точнее вход, тем меньше переделок. Голосом это делать быстрее — за этим и нужна диктовка.
  • Принимать код без ревью Читать код самому не нужно — это работа второго агента. Один написал, второй проверил: /code-review или «найди проблемы, не исправляй». Минута, и ловится то, что по результату не видно.
  • Класть ключи и пароли прямо в код Пароли и ключи хранят в отдельном файле, который не попадает в облако. Иначе ключ уедет в публичный репозиторий и его найдут за часы. Разберём на занятии.
  • Копить изменения огромными кусками Проси одну задачу за раз и сразу проверяй результат. Двадцать правок за один запрос почти гарантированно приедут с ошибкой, которую потом не найти.
