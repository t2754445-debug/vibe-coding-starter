# Стартовый набор вайб-кодера

Памятка для подготовительного этапа: что установить самому и какими нейросетями будем работать.

**Открыть страницу:** https://t2754445-debug.github.io/vibe-coding-starter/

## Что внутри

- **Что установить самому** — Happ (VPN), VS Code, Docker Desktop, Python, superwhisper для диктовки. В каждом пункте сначала ссылка на скачивание, потом пошаговая инструкция мышкой; команды терминала спрятаны под раскрывающийся блок и не обязательны.
- **Два аккаунта** — Gmail и GitHub, просто регистрация.
- **Что поставим вместе** — Homebrew, Git, Node.js, Codex, Claude Code. Это уже на занятии.
- **Чем работаем** — Codex (основной на старте), Claude Code (рекомендую следом), варианты: DeepSeek API, GitHub Copilot, локальные Ollama и LM Studio.
- **Сводная таблица**, **три рабочих связки**, **пять типичных ошибок**, **все ссылки одним списком**.

Инструкции переключаются между **macOS** и **Windows** кнопкой в шапке; по умолчанию открывается вариант под систему посетителя.

## Как редактировать

Вся страница — один файл [`index.html`](index.html), без сборки и зависимостей. Правишь, коммитишь, пушишь — GitHub Pages обновляется сам за минуту.

Тарифы и ссылки меняются: перед отправкой ученику стоит бегло сверить цены на официальных сайтах.
