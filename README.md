# Стартовый набор вайб-кодера

Памятка для подготовительного этапа: что установить и какими нейросетями работать.

**Открыть страницу:** https://t2754445-debug.github.io/vibe-coding-starter/

## Что внутри

- **Установка по шагам** — Happ (VPN), Homebrew, VS Code, Docker Desktop, Git, Node.js, Python, почта Gmail, аккаунт GitHub, OpenAI Codex, Claude Code. Каждый шаг с пошаговой инструкцией и проверкой результата. Инструкции переключаются между **macOS** и **Windows** кнопкой в шапке.
- **Проверка** — команды, которые должны вернуть версию, и что делать, если не вернули.
- **Чем работаем** — Codex (основной на старте), Claude Code (рекомендую следом), варианты: DeepSeek API, GitHub Copilot, Cursor, локальные Ollama и LM Studio с требованиями по железу.
- **Сводная таблица** — формат, цена, порог входа, автономность, роль.
- **Три рабочих связки** — от $0 до $40 в месяц.
- **Первый проект за 15 минут** и **пять типичных ошибок новичка**.
- **Все ссылки одним списком** — проверенные, только официальные источники.

## Как редактировать

Вся страница — один файл [`index.html`](index.html), без сборки и зависимостей. Правишь, коммитишь, пушишь — GitHub Pages обновляется сам за минуту.

Тарифы и ссылки меняются: перед тем как отдавать памятку ученику, стоит бегло сверить цены на официальных сайтах.
