# Стартовый набор вайб-кодера

Памятка для тех, кто начинает писать код вместе с нейросетями.

**Открыть страницу:** https://t2754445-debug.github.io/vibe-coding-starter/

## Что внутри

- **Установка по шагам** — терминал и Homebrew, VS Code, Git, Node.js, Python, GitHub, Docker Desktop, Claude Code. Инструкции переключаются между **macOS** и **Windows** кнопкой в шапке.
- **Проверка** — команды, которые должны вернуть версию, и что делать, если не вернули.
- **Нейросети для кода** — Claude Code, OpenAI Codex, DeepSeek API, GitHub Copilot, Cursor, Gemini, локальные модели. Плюсы, минусы, порядок цен.
- **Сводная таблица** — формат, цена, порог входа, автономность.
- **Три сценария выбора** — бесплатный старт, оптимальный старт, боевая связка.
- **Первый проект за 15 минут** и **пять типичных ошибок новичка**.

## Как редактировать

Вся страница — один файл [`index.html`](index.html), без сборки и зависимостей. Правишь, коммитишь, пушишь — GitHub Pages обновляется сам за минуту.

Тарифы и ссылки меняются: перед тем как отдавать памятку ученику, стоит бегло сверить цены на официальных сайтах.
