## Что в репозитории

### Страницы

- **[index.html](index.html)** — пошаговая установка: Happ (VPN), VS Code, Docker, Python,
  superwhisper. Ссылка → инструкция мышкой → команда терминала под спойлером.
  Плюс аккаунты, чек-лист прогресса и обзор нейросетей для кода.
- **[course.html](course.html)** — программа занятия на 5 часов с таймингом и целями блоков.
- **[present.html](present.html)** — те же пять часов слайдами, для ведения с экрана.
  Стрелки листают, `Esc` показывает все слайды, `F` — полный экран, место запоминается.

### [starter-kit/](starter-kit/) — рабочее окружение и методика

Папка, которую ученик открывает в VS Code. Файлы читает не только человек,
но и агент: `SETUP.md` — прямая инструкция «настрой мне компьютер».

```text
starter-kit/
├── SETUP.md              инструкция агенту на автонастройку macOS
├── CLAUDE.md / AGENTS.md правила работы агента во всех проектах
├── 01-инструменты/       VS Code для Mac, MCP-серверы, терминал и Git
├── 02-методология/       ⭐ думать до промпта, архитектура, стек, промпты,
│                         проверка без чтения кода
├── 03-скиллы/            как устроены, как создать свой, готовые примеры
├── 04-программа/         план занятия с заметками преподавателю
└── 05-ресурсы/           подборки на GitHub, что не вошло в набор
```

## Главные мысли

**Час на продумывание экономит день на переделках.** Пять вопросов до первой строки:
что делает (одно предложение без «и») → кто пользуется → что на входе и выходе →
чего НЕ делает → как понять, что готово.

**По одному шагу.** В большом запросе ошибка находится в конце, в маленьком — сразу.

**Коммит после каждого работающего шага.** Git — кнопка «отменить» на весь проект.

**Не читаешь код — ставь ревью.** Нейросеть уверенно напишет неработающий код
и так же уверенно объяснит, почему он правильный. Защита — не чтение,
а второй агент: один пишет, другой проверяет.

## Как забрать материалы

Ученику достаточно ссылки на репозиторий. Два пути:

**Без Git** (проще, если только начинает):
[скачать архивом](https://github.com/t2754445-debug/vibe-coding-starter/archive/refs/heads/main.zip)
→ распаковать → открыть папку `starter-kit` в VS Code.

**С Git** (когда уже установлен):

```bash
git clone https://github.com/t2754445-debug/vibe-coding-starter.git ~/Projects/starter
code ~/Projects/starter/starter-kit
```

Дальше в обоих случаях — сказать агенту:
`Прочитай SETUP.md и выполни всё, что там написано.`

## Как редактировать

Страницы — обычный HTML без сборки. Правишь → коммит → push → GitHub Pages обновляется за минуту.
Картинка превью для мессенджеров генерируется скриптом `make-og.py`.
