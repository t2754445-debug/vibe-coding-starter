# Как выбирать стек

> Стек — это набор технологий, на которых пишется проект: язык, библиотеки, база, хостинг.
> Хорошая новость: **в 95% задач выбор очевиден**, и агент сделает его сам.
> Плохая: если стек не назвать явно, агент выберет модный, а не подходящий.

---

## Главное правило

**Стек выбирается под задачу, а не под моду.**

Второе по важности: **выбирай то, чего в интернете много.** У популярной технологии
больше примеров, больше ответов на форумах — и, что важнее для нас,
модель видела её в тысячах проектов при обучении. На редкой библиотеке
агент начнёт выдумывать несуществующие функции.

Третье: **один проект — один язык.** Пока не появилась причина, которую можно назвать вслух.

## Готовые связки под типовые задачи

Таблица закрывает почти всё, что делает начинающий. Просто найди свою строку.

| Что делаешь | Стек | Почему так |
|---|---|---|
| Обработать Excel, посчитать, сохранить | Python + `pandas` + `openpyxl` | Стандарт для таблиц, примеров бесконечно |
| Собрать данные с сайта | Python + `requests` + `BeautifulSoup` | Для простых сайтов. Если сайт на JavaScript — `playwright` |
| Телеграм-бот | Python + `aiogram` | Самая живая библиотека для ботов, документация на русском |
| Автоматизация: переименовать, разложить, объединить | Python, без библиотек | Встроенных модулей хватает |
| Простой сайт-визитка, лендинг | HTML + CSS, без фреймворков | Фреймворк здесь — из пушки по воробьям |
| Сайт с формами и личным кабинетом | Next.js (React) + Tailwind | Самый ходовой стек, агенты знают его лучше всего |
| Сервер, API для мобильного приложения | Python + FastAPI | Быстро пишется, автоматическая документация |
| Дашборд с графиками для себя | Python + Streamlit | Интерфейс без вёрстки, за час готово |
| Хранение данных: до тысяч строк | SQLite | Просто файл, ничего не ставится |
| Хранение данных: несколько пользователей | PostgreSQL в Docker | Вот теперь Docker и пригодился |

Отдельно про хостинг — куда выложить результат:

| Что | Куда | Цена |
|---|---|---|
| Статическая страница, лендинг | GitHub Pages | Бесплатно |
| Сайт на Next.js | Vercel | Бесплатно для личных проектов |
| Телеграм-бот, скрипт по расписанию | VPS за 200–500 ₽/мес | Дёшево, но нужен минимум администрирования |
| Программа для себя | Никуда, запускай локально | Бесплатно |

## Почему стек лучше называть явно

Агент выбирает по своим соображениям, и они не всегда совпадают с твоими.

```text
Плохо:  «Сделай телеграм-бота, который присылает погоду»
        → агент может взять любую из пяти библиотек, а через месяц ты не вспомнишь какую

Хорошо: «Сделай телеграм-бота на Python с aiogram 3. Погоду брать с api.open-meteo.com.
         Без базы данных, город зашит в настройках.»
        → предсказуемый результат
```

Когда стека в голове нет — не выдумывай, спроси:

```text
Задача: [описание].
Предложи 2–3 варианта стека с плюсами и минусами каждого.
Учти, что я новичок и проект буду поддерживать один.
Не пиши код, только сравнение и рекомендацию.
```

Это ровно тот случай, когда агент полезнее поиска: он знает, что с чем сочетается.

## Как проверить чужой (или свой) выбор

Четыре вопроса к любому предложенному стеку:

1. **Сколько лет технологии и жива ли она?** Последний релиз год назад — плохой знак.
2. **Смогу ли я это запустить у себя за 15 минут?** Нужен кластер Kubernetes — не для тебя.
3. **Что будет, если разработчик библиотеки её забросит?** Есть ли альтернативы.
4. **Сколько это стоит в месяц при моих объёмах?** Бесплатный тариф часто кончается на 100 запросах.

Красные флаги в ответе агента:

- «Возьмём микросервисы» — для проекта, который делает один человек.
- «Нужен Kubernetes» — почти никогда не нужен.
- Библиотека, у которой на GitHub меньше тысячи звёзд, при наличии популярного аналога.
- Технология, вышедшая в этом году: примеров мало, модель её толком не видела.

## Как это связано со скиллами

Ты можешь не выбирать стек каждый раз вручную. Если в правилах агента
(файл `CLAUDE.md`) или в скилле записаны твои предпочтения — агент будет применять их сам:

```markdown
## Стек по умолчанию
- Скрипты и обработка данных: Python 3.12, pandas
- Телеграм-боты: aiogram 3
- Веб: Next.js + Tailwind, без лишних UI-библиотек
- База: SQLite, пока не потребуется несколько пользователей
- Тесты: pytest

Отклоняешься от этого списка — сначала объясни почему.
```

Записал один раз — работает во всех проектах. Именно поэтому опытный пользователь
редко думает о стеке: решение принято заранее и лежит в правилах, а не в голове.

Подробнее про скиллы — в папке `03-скиллы`.

---

## Одно исключение из всех правил

Если задача учебная и цель — **разобраться**, а не получить результат,
бери то, что интереснее. Учиться на скучном не получается.

Но такой проект сразу помечай как учебный и не тащи его решения
в рабочие — там правила другие.
