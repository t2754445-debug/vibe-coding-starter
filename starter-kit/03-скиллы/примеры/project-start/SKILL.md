# Начало проекта

Порядок обязателен, шаги не пропускать.

## 1. Вопросы

Задай пользователю вопросы по одному, дождись ответа на каждый:

- Что программа делает — одним предложением, без «и»?
- Кто пользуется и как часто?
- Что на входе, что на выходе? Попроси показать реальный пример данных.
- Чего программа НЕ делает?
- Как понять, что готово?

Не переходи дальше, пока нет ответов на все пять.

## 2. SPEC.md

Собери файл `SPEC.md` — описание поведения, без кода:

- что происходит при нормальных данных;
- что происходит при кривых данных (пусто, не тот формат, дубликаты);
- формулы и правила расчёта, если они есть;
- явный раздел «Не делаем».

Покажи файл пользователю и спроси, что поправить.

## 3. PLAN.md

Разбей на шаги. У каждого шага — проверяемый результат.
Каждый шаг должен заканчиваться чем-то работающим, а не «половиной функции».

## 4. Git

```bash
git init
git add SPEC.md PLAN.md
git commit -m "Спецификация и план"
```

## 5. Код

Только теперь. По одному шагу за запрос, с остановкой и показом результата.

## Запреты

- Не начинать с кода.
- Не делать несколько шагов плана за один раз.
- Не добавлять возможности, которых нет в SPEC.md.
