# VS Code на Mac: расширения и настройка

> Список собран из реального рабочего окружения и почищен: убрано то,
> что на Mac не имеет смысла или дублируется.
> Ставить всё сразу не надо — первые шесть, остальное по мере надобности.

---

## Как ставить

Два способа, оба рабочие.

**Мышкой:** в VS Code слева значок с квадратиками (Extensions) или `Cmd + Shift + X`,
вбить название, нажать Install.

**Командой** (быстрее, если ставишь пачкой) — во встроенном терминале `Ctrl + \``:

```bash
code --install-extension <идентификатор>
```

Идентификаторы указаны в таблицах ниже.

---

## Обязательный минимум (6 штук)

| Расширение | Идентификатор | Зачем |
|---|---|---|
| **Russian Language Pack** | `MS-CEINTL.vscode-language-pack-ru` | Русский интерфейс. Ставится первым, дальше проще |
| **Codex** | `openai.chatgpt` | Наш основной AI-агент. Входит в подписку ChatGPT Plus |
| **Claude Code** | `anthropic.claude-code` | Второй агент, для сложных задач. Отдельная подписка |
| **Python** | `ms-python.python` | Запуск Python по кнопке ▶, отладка, выбор версии |
| **Pylance** | `ms-python.vscode-pylance` | Подсказки и подсветка ошибок в Python до запуска |
| **GitLens** | `eamodio.gitlens` | Видно, когда и что менялось в каждой строке. Спасает при откатах |

Одной командой:

```bash
code --install-extension MS-CEINTL.vscode-language-pack-ru
code --install-extension openai.chatgpt
code --install-extension anthropic.claude-code
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension eamodio.gitlens
```

## Что на Mac НЕ нужно

Из рабочего окружения на Windows это ставить не надо:

| Что | Почему |
|---|---|
| PowerShell (`ms-vscode.powershell`) | Это оболочка Windows. На Mac — `zsh`, он встроен |
| Edge DevTools | Отладка через Edge; на Mac используется Safari или Chrome |
| Gemini Code Assist, Cloud Code | Отдельная экосистема Google, в нашей связке не участвует |
| DeepSeek for Copilot | Нужен только вместе с подпиской Copilot; проще подключить DeepSeek через Continue |
| LM Studio Copilot Provider | Только если поднимаешь локальные модели |

## Настройки, которые стоит поменять сразу

Открой настройки: `Cmd + ,` → в поиске введи название параметра.

| Параметр | Значение | Что даёт |
|---|---|---|
| `Files: Auto Save` | `afterDelay` | Файлы сохраняются сами. Одной проблемой меньше |
| `Editor: Word Wrap` | `on` | Длинные строки переносятся, не надо скроллить вбок |
| `Editor: Font Size` | `14`–`16` | По глазам |
| `Terminal › Integrated: Font Size` | `13`–`14` | То же для терминала |
| `Editor: Minimap` | выключить | Освобождает место справа |

## Горячие клавиши, которые реально используются

| Сочетание | Что делает |
|---|---|
| `Ctrl + \`` | Открыть/закрыть терминал. **Главное сочетание** |
| `Cmd + P` | Быстрый переход к файлу по названию |
| `Cmd + Shift + P` | Палитра команд: любое действие по названию |
| `Cmd + B` | Спрятать/показать боковую панель |
| `Cmd + /` | Закомментировать строку |
| `Cmd + S` | Сохранить |
| `Cmd + Z` | Отменить |
| `Cmd + Shift + F` | Поиск по всем файлам проекта |
| `Cmd + Shift + X` | Панель расширений |

Отдельно: `code .` в терминале открывает текущую папку в VS Code.
Чтобы эта команда заработала, один раз выполни `Cmd + Shift + P` → `Shell Command: Install 'code' command in PATH`.

## Как выглядит рабочее окно

```text
┌──────────┬────────────────────────────┬───────────────┐
│ Файлы    │  Код                       │  Агент        │
│ проекта  │                            │  (Codex)      │
│          │                            │               │
├──────────┴────────────────────────────┴───────────────┤
│  Терминал (Ctrl + `)                                  │
└───────────────────────────────────────────────────────┘
```

Всё в одном окне: слева файлы, посередине код, справа чат с агентом, внизу терминал.
Переключаться между программами не нужно — в этом весь смысл.
