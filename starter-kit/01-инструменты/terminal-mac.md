# Терминал на Mac: необходимый минимум

> Терминал — это окно, где программы отвечают текстом вместо кнопок.
> Пугает ровно до того момента, пока не выучишь семь команд.
> Открывается прямо в VS Code: `Ctrl + \`` (клавиша с буквой «ё»).

---

## Как устроено

Ты всегда находишься **в какой-то папке**. Команды выполняются относительно неё.
Текущая папка показана в приглашении слева от курсора.

```bash
~/Projects/hello-vibe %
```

Здесь `~` — твоя домашняя папка, то есть `/Users/имя`.

---

## Семь команд, которых хватит надолго

| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | Показать, где я сейчас | `pwd` |
| `ls` | Показать, что в папке | `ls -la` (с подробностями) |
| `cd` | Перейти в папку | `cd ~/Projects` |
| `cd ..` | Подняться на уровень выше | `cd ..` |
| `mkdir` | Создать папку | `mkdir новый-проект` |
| `open` | Открыть файл или папку | `open .` (откроет папку в Finder) |
| `code` | Открыть в VS Code | `code .` (откроет текущую папку) |

Этого достаточно, чтобы дойти до нужного места и запустить проект.

---

## Приёмы, которые экономят время

**Tab дополняет.** Начни печатать название папки и нажми `Tab` — дописывается само.
Экономит время и защищает от опечаток.

**Стрелка вверх повторяет.** Предыдущая команда — на `↑`. Ещё раз `↑` — позапрошлая.

**Перетаскивание работает.** Перетащи папку из Finder в терминал — вставится полный путь.
Самый простой способ попасть в нужное место: набрать `cd `, перетащить папку, нажать `Enter`.

**Ctrl + C прерывает.** Программа зависла или бесконечно что-то печатает — `Ctrl + C`.

**clear чистит экран.** Или `Cmd + K`.

---

## Что означают непонятные штуки

| Символ | Значение |
|---|---|
| `~` | Домашняя папка, `/Users/твоё-имя` |
| `.` | Текущая папка |
| `..` | Папка уровнем выше |
| `/` | Разделитель в пути (на Windows — `\`, здесь наоборот) |
| `%` или `$` | Приглашение: терминал ждёт команду |
| `sudo` | «Выполнить от администратора» — попросит пароль |

**Про пароль:** когда терминал спрашивает пароль от Mac, **символы не отображаются** —
ни точек, ни звёздочек. Кажется, что ввод не работает. Это нормально: печатай вслепую и жми `Enter`.

---

## Три команды, с которыми осторожно

| Команда | Что делает | Опасность |
|---|---|---|
| `rm` | Удаляет файлы | Мимо корзины, безвозвратно |
| `rm -rf папка` | Удаляет папку со всем содержимым | То же, только целую папку |
| `sudo` что угодно | Выполняет от администратора | Может сломать систему |

Правило: **никогда не вставляй команду, которую не понимаешь.**
Не понял — спроси у агента: «объясни, что делает эта команда, прежде чем я её выполню».

## Git: пять команд для ежедневной работы

Git — это история проекта и кнопка «отменить» на всё сразу.

| Команда | Что делает |
|---|---|
| `git init` | Начать следить за папкой (один раз в новом проекте) |
| `git status` | Что изменилось с прошлого сохранения |
| `git add .` | Отметить все изменения для сохранения |
| `git commit -m "описание"` | Сохранить версию с подписью |
| `git log --oneline` | Список сохранённых версий |

Рабочий цикл выглядит так:

```bash
# сделал шаг, проверил, что работает
git add .
git commit -m "Расчёт прибыли по одной строке"
```

Откатиться к последнему сохранению, если всё сломалось:

```bash
git checkout .       # отменить незакоммиченные изменения
```

Правило: **коммить после каждого работающего шага.** Не в конце дня, не когда «доделаю» —
именно после каждого шага, который работает. Это две секунды, и они окупаются первый же раз,
когда агент сломает то, что до этого работало.

## Отличия от Windows, если раньше работал там

| Windows | Mac |
|---|---|
| `dir` | `ls` |
| `cd C:\Папка` | `cd /Users/имя/Папка` |
| Обратный слэш `\` | Прямой слэш `/` |
| `C:\Users\Имя` | `/Users/Имя` или `~` |
| PowerShell | zsh (встроен) |
| `python` | `python3` |
| `Ctrl + C` копировать | `Cmd + C` копировать |

Главное, что сбивает: **`python` на Mac не работает, нужно `python3`.** Это не поломка,
так устроено специально — системный Python отделён от того, что ставишь ты.
