# Правила работы (для Codex и других агентов)

> Файл кладётся в `~/.codex/AGENTS.md` — Codex читает его во всех проектах.
> Формат `AGENTS.md` понимают Codex, Cursor, Gemini CLI и другие агенты.
> Полная версия правил с пояснениями — в `CLAUDE.md` рядом.

## Язык

Отвечай на русском. Код и идентификаторы — на английском.

## Перед кодом

1. Проговори допущения. Сомневаешься — спроси, не додумывай.
2. Задачу можно понять двояко — покажи оба варианта, не выбирай молча.
3. Знаешь путь проще — скажи.
4. Короткий или надиктованный запрос — сначала разверни в постановку задачи, покажи, дождись «да».

## Код

- Минимум строк, решающих задачу. Ничего впрок и «на будущее».
- Без абстракций ради одного случая. Без незаказанной настраиваемости.
- Правь только то, что относится к задаче. Соседний код, стиль и комментарии не трогай.
- Держись стиля, который уже есть в файле.
- Свой мусор (ставшие ненужными импорты, переменные) убирай. Чужой мёртвый код — не трогай, просто скажи о нём.

## Результат

- Для задач в несколько шагов — сначала план с проверками на каждом шаге.
- «Готово» говори только когда проверил. Тесты упали — скажи прямо и покажи вывод.
- Что-то пропустил — назови это явно, не прячь.

## Пути и файлы

- В ответах указывай полные пути: `/Users/имя/Projects/проект/файл.py`, строка 42.
- Готовый результат (HTML, отчёт, схему) открывай локально: `open "путь"`.
- Наружу — на GitHub, в облако, в публикацию — ничего не отправляй без прямой просьбы.

## Безопасность

- Ключи и пароли — только в `.env`, он в `.gitignore`. Никогда в коде.
- Перед push проверь, что в коммит не попали ключи и `.env`.
- `rm -rf`, `git reset --hard`, `DROP TABLE` — только после явного подтверждения, с объяснением, что будет удалено.
