## SEO — около 30 скиллов

Полноценный рабочий инструментарий, не игрушка.

| Что умеет | Скиллы |
|---|---|
| Полный аудит сайта | `seo-audit` — обходит до 500 страниц, определяет тип бизнеса, запускает до 15 специалистов параллельно, выдаёт оценку здоровья |
| Техническая часть | `seo-technical` — индексация, Core Web Vitals, мобильная версия, рендеринг JS |
| Контент | `seo-content`, `seo-content-brief`, `seo-page` — качество, E-E-A-T, брифы на тексты |
| Семантика | `seo-cluster` — кластеризация запросов по реальным пересечениям выдачи, схема «хаб и спицы» |
| Локальный бизнес | `seo-local`, `seo-maps` — карточка в картах, гео-сетка позиций, отзывы, NAP |
| Оптимизация под AI-ответы | `seo-geo` — видимость в AI Overviews, ChatGPT, Perplexity |
| Разметка и структура | `seo-schema`, `seo-sitemap`, `seo-hreflang`, `seo-images` |
| Ссылки | `seo-backlinks` — профиль ссылок, токсичные, разрывы с конкурентами |
| Платные источники | `seo-dataforseo`, `seo-ahrefs`, `seo-seranking`, `seo-profound`, `seo-firecrawl` |

**Когда пригодится:** если появится свой сайт или клиентский проект, где нужен трафик из поиска.
Часть скиллов требует платных API-ключей.

## Разработка и деплой — набор gstack, около 40 скиллов

Инструменты продуктовой разработки: не «написать скрипт», а вести живой продукт.

| Направление | Что умеет |
|---|---|
| Тестирование в браузере | `browse`, `qa` — открывает сайт, кликает, находит баги и чинит их |
| Ревью с разных ролей | `plan-ceo-review`, `plan-eng-review`, `plan-design-review`, `plan-devex-review` — один и тот же план смотрят «продуктолог», «инженер», «дизайнер» и «разработчик со стороны» |
| Отладка | `investigate` — систематический поиск корневой причины, а не симптома |
| Деплой | `land-and-deploy`, `canary` — выкатка с наблюдением за первыми минутами |
| Дизайн-ревью | `design-review`, `design-shotgun` — ищет визуальные несостыковки, генерирует варианты дизайна на сравнение |
| Контекст сессии | `context-save`, `context-restore` — сохранить рабочее состояние и вернуться к нему завтра |
| Безопасность работы | `careful`, `guard`, `freeze` — ограничить агенту зону правок, предупреждать о разрушительных командах |
| iOS | `ios-qa`, `ios-fix`, `ios-design-review` — тестирование на живом устройстве |
| Ретроспективы | `retro`, `health`, `office-hours` — разбор недели, качество кодовой базы |

**Когда пригодится:** когда появится продукт, которым пользуется кто-то кроме тебя.
Из всего набора новичку раньше всего понадобится `investigate` — отладка.

## Субагенты — узкие специалисты

Отличаются от скиллов тем, что работают **в отдельном окне контекста**: получают задачу,
делают её у себя и возвращают результат, не засоряя основной разговор.

Два примера из живых проектов:

- **`economics-guardian`** — сторож юнит-экономики: себестоимость, комиссии, логистика,
  налог, маржа, ROI. Вызывается при любом изменении формул, гоняет тесты, блокирует регрессии.
  Явно прописано, чего он **не** делает: не лезет в API и интерфейс.
- **`marketplace-api-integrator`** — только API трёх маркетплейсов: авторизация,
  ограничения по частоте запросов, пагинация, повторы, асинхронная загрузка цен.

Это правильный пример: **узкая зона ответственности и явные границы.**
Когда дойдёшь до своих субагентов — делай так же.

## Как подключить, когда понадобится

**Плагины** — встроенный магазин, один клик:

```text
/plugin
```

**Скилл со стороны** — скопировать папку в `~/.claude/skills/`. Обязательно прочитать
`SKILL.md` перед установкой: это инструкции, которые агент выполнит.

**Из моего набора** — просто скажи, какая задача появилась. Отдам нужное с пояснением,
как пользоваться. Отдавать всё сразу смысла нет: непонятно, что из этого твоё.

## Что не отдаётся никогда

- **API-ключи и токены** — DataForSEO, Ahrefs, Stripe, Cloudflare и прочие. Ключи личные,
  привязаны к оплате.
- **Проектные конфигурации клиентов** — настройки и данные из рабочих проектов.
- **Личная память агента** — файлы с разбором стиля и предпочтений. Они бесполезны для другого
  человека: там записано, как писать **за меня**, а не за тебя. Свои такие ты наработаешь сам
  за пару месяцев — и они будут ценнее скачанных.
